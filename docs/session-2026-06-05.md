`agents/rl_agent.py` — wraps a `MaskablePPO` checkpoint as an `Agent`.

- Used for post-training benchmarking via `--checkpoint`.

### Key discovery: per-hand win rate has a ~70% ceiling
Single-hand Truco is dominated by deal variance. Even the best agent vs the worst opponent caps at ~70% per hand. **90%+ is only achievable in full match play**, where skill compounds across hands.

Match play confirmed: `TrucoEnv` already defaults to `target=40`, so the RL training was already match-aware.


Then benchmark each checkpoint until 90% is crossed. The model was improving fast — 2M→more steps should push past 85.3%.

### If threshold training plateaus before 90%: self-play with high threshold_mix
Self-play with `threshold_mix=0.5` (50% Threshold opponents) prevents forgetting rule-based strategies while still learning from self-play diversity. Check `training/env.py` for the `threshold_mix` parameter.

### Benchmark speed problem
